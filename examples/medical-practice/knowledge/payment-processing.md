# Payment Processing — Card-on-File & Refunds SOP
> HYPOTHETICAL EXAMPLE POLICY — fictional practice. Fictional procedures.

## Card on file (COF)
1. Written consent form **FD-21** signed before any storage. The terminal
   stores a token only — the front desk never sees or records the number.
2. COF charges allowed for: co-pays at check-in, no-show fee **after** one
   warning, and lab patient portions over $25 (with estimate first).
3. Each COF charge: tell the patient before running it; hand/receipt the
   card slip. Log amount + reason in the day sheet.
4. Token expires with the card; refresh re-consents (FD-21 again).

## Refunds
- Duplicate charge: refund same day to the same card, note `REF-DUP`.
- Disputed charge: do not argue at the desk — refund form **FD-26** to the
  manager; patient gets the copy, not a promise.

## Never
- Write, type, or photograph a full card number anywhere — including "just
  for today", sticky notes, or chat systems like this one.
- Store a card from a verbal yes; consent is the signed FD-21.
- Process a refund to a different card, cash, or gift card.
