Sekka.

A small, honest terminal chat client for any OpenAI-compatible LLM endpoint.
vLLM · llama.cpp · Ollama · LM Studio · anything with /v1/chat/completions.

GitHub repository README

Install

git clone https://github.com/nkavassalis/sekka.git
cd sekka
pip install -e .

Run

sekka --endpoint http://my-vllm-box:8000/v1

No model? Sekka asks the endpoint's /models and lets you pick. Everything (--endpoint, --model, --system, keys, colors) can also live in .sekka/config.json or be edited in-app with /config.

What you get

  • Plain TUI chat — scrollable history, multi-line input, no mouse required
  • Model discovery from any OpenAI-compatible server
  • Timing line after every reply: [1.4s, 38.2 tok/s]
  • /save to timestamped JSON/Markdown — nothing is written unless you ask
  • Configurable colors and key bindings; layered CLI > env > file config

Slash commands

commandwhat it does
/helpcommands & current key bindings
/savesave history to a timestamped file (asks first)
/configin-app configuration screen
/modelsre-fetch models and pick one
/clearclear the chat
/exitquit (ctrl+q also works)

Why “sekka”?

雪華 — sekka — “snowflake”: each chat crystallises one exchange at a time, and no two are alike. Like a good terminal tool it stays close to the metal: no accounts, no telemetry, no cloud — it talks to the inference server you point it at.
